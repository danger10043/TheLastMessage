# 재사용 시네마틱 제어

`AOnceCinematicController`를 맵에 배치하고 다음 값을 설정한다.

- CinematicId: 맵 안에서 고유하며 이후 변경하지 않는 재생 기록 ID.
- SequenceActor: 재생할 Level Sequence Actor. 해당 액터의 Auto Play는 끈다.
- PlayOnBeginPlay: 맵 진입 시 재생할 때 사용.
- SkipOnLoad: 저장 파일에서 불러온 맵의 진입 연출을 생략할 때 사용. 다른 맵의 첫 방문까지 생략하지 않는다.
- TriggerActor: 플레이어와 Overlap 이벤트가 발생하는 액터. 진입 시 재생한다. 자동 시작이 아니라면 선택한다.
- CleanupActors: 재생 종료 또는 이미 본 연출 생략 시 제거할 연출 전용 액터.
- Boss: 맵 시작부터 보스 인트로 진입 전과 재생 중 UI를 숨기고, 종료 또는 트리거 진입 후 생략 시 표시할 보스. 체크포인트 근처에서 AI가 감지하더라도 인트로 진입 전에는 HP 바가 나타나지 않는다. 일반 연출에는 비워 둔다.

현재 공장 맵에는 Cinematic_FactoryEntry와 Cinematic_BossIntro 두 제어 액터를 배치했다. 기존 레벨 블루프린트의 EventGraph, StartLS, EndLS를 제거해 중복 실행을 막았다. 보스 인트로 트리거 액터의 기존 충돌 영역을 그대로 사용한다.

재생 기록은 저장 슬롯의 맵별 PlayedCinematics에 저장한다. 재생을 시작할 때 기록하므로 중간에 중단한 연출도 반복하지 않는다. 기록만 저장할 때는 체크포인트 위치나 플레이어 스냅샷을 갱신하지 않는다. 진행 중인 저장이 있으면 다음 쓰기에 기록을 포함한다. 새 게임으로 슬롯을 새로 시작하면 기록도 초기화된다. 기존 저장 파일에 기록 필드가 없어도 불러온 맵의 진입 연출은 생략한다. 아직 기록되지 않은 보스 연출은 이후 첫 진입 시 재생한다.

시퀀스 종료, Stop, 제어 액터 제거 시 플레이어 숨김·입력·HUD 상태를 복구한다. 맵이나 액터 이름을 C++ 코드에 고정하지 않는다.

Boss가 연결된 연출은 재생 중 AI 판단·이동과 진행 중인 공격을 중단하고 Cinematic 상태로 새 공격을 막는다. 종료 또는 중단 시 보스 상태와 이 제어기가 일시정지한 AI를 복구한다. 취소한 공격은 Combat 상태로 돌아가며, 이미 본 연출 생략 시에는 전투를 중단하지 않는다.
