# 밀기·당기기 간격과 자세 보정

## 영상 피드백 후 추가 수정

### 큰 상자 잡기 자세와 접근 보완

상자 윗면을 기준으로 손을 배치하면 큰 상자에서 양팔을 위로 들게 되는 문제가 있었다. 현재는 상호작용 시작 시 캐릭터 양어깨 평균보다 12cm 낮은 높이를 기준으로, 상자 표면 범위 안의 접촉점을 정한다. 양손 간격은 어깨 폭에 맞추며, 팔꿈치의 굽힘 방향을 아래쪽으로 조정했다. 당기기 시퀀스의 손목 회전도 기본 대기 자세 기준으로 보정했다.

먼 거리 접근은 즉시 이동에서 거리 비례 0.2~0.5초의 smoothstep 이동으로 교체했다. 접근 중에는 걷기 동작을 사용하고 양팔 IK는 비활성화한다. 접근이 끝난 뒤 잡기 동작과 IK를 적용한다. 장애물로 접근이 막히면 상호작용을 종료한다.

`Saved/Logs/BoxGripApproachTests.log`: 일반 크기와 2배 크기 상자, 양쪽 방향, 30/120fps에서 접근이 한 프레임에 끝나지 않는지, 도착 후 접촉 거리, 어깨보다 낮은 잡기 높이, 양손 접촉, 이동·정지 안정성 및 상태 복구 검증에 통과했다. 렌더링된 최종 외형에 대한 시각 검토는 포함하지 않는다.

첨부된 23.31초 영상에서 양손이 상자를 잡지 못하는 자세와 왼쪽 당기기 정체를 확인했다. 앞선 보정은 기존 손 위치를 유지하는 데 그쳐 실제 상자 접촉을 보장하지 못했다.

- AnimBP 최종 출력에 양팔 Two Bone IK를 추가했다. 실제 상자 Bounds에서 앞면의 두 접촉점을 계산하고 캐릭터 메시 좌표로 전달한다. 밀기·당기기·정지 시 모두 양손을 맞추며, 조작 종료 시 0.1초에 걸쳐 해제한다. 팔 길이는 늘리지 않는다.
- 상호작용 시작 위치를 그대로 유지하지 않고, 상자 표면에서 캡슐 반경+3cm 위치까지 캐릭터를 충돌 검사와 함께 이동시킨다. 경로가 막혀 접근할 수 없으면 시작하지 않는다.
- 조작자와 상자 사이에만 물리 충돌을 끄는 자유 제약을 두고 종료 시 제거한다. 상자가 자기 조작자의 캡슐에 막히는 상황을 피한다. 바닥·벽·다른 물체와의 충돌은 유지한다.
- X축 물리 속도를 가속도 제한 내에서 제어하고 Z축 속도는 유지한다.
- 밀기/당기기 애니메이션은 매 프레임 초기화되는 캐릭터 걷기 속도 대신 실제 따라간 이동 속도로 선택한다.

추가 검증: 실제 TNT 메시·Robbie 메시·AnimBP로 최대 거리 접근, 양손 접촉, Pull 몽타주 선택, 양방향 밀기/당기기, 벽 충돌, 종료 복구를 확인했다. `Saved/Logs/BoxGripSyncTests.log`의 테스트 결과는 성공이다. 30fps에서 좌/우 당기기 속도 117.094/117.099cm/s, 120fps에서 134.272/134.272cm/s였다. 전환 구간을 포함한 양손 접촉 오차는 최대 1.91cm 이하였다.

AnimBP 수정 직전 백업은 `Saved/BoxGripBackup`에 있다. 제출된 영상의 장면 추출은 `Saved/VideoReview`에 보관했다.

## 수정

- 플레이어와 물체가 각각 목표 속도를 향해 이동하던 방식을 변경했다. 조작 중 캐릭터의 독립 걷기를 멈추고, 물리 시뮬레이션 이후 상자의 실제 X 위치를 기준으로 잡기 시작할 때의 좌우 간격을 유지한다.
- 캐릭터 이동은 `CharacterMovement.MoveSmooth`를 사용해 충돌과 경사·턱 처리를 유지한다. 플레이어가 장애물에 막혀 간격을 유지할 수 없으면 조작을 종료한다. 종료 시 걷기 속도·회전 설정·물리 상호작용·임시 충돌 무시를 복구한다.
- `A_Push_Heavy_01_Loop1`은 루트 위치가 재생 중 앞으로 움직이는 데이터가 있었다. 루트를 고정해 제자리 밀기 동작으로 재생한다. 이로써 메시가 상자에 들어갔다가 루프 시작 시 뒤로 돌아오는 원인도 제거한다.
- 기존 `AS_Pull_BoxSides`에서 `AS_Pull_BoxParallel`을 만들어 당기기 몸통의 좌우 비틀림을 보정했다. 모든 프레임에서 양쪽 쇄골을 연결한 선을 상자 면과 평행하게 맞췄다. 팔은 회전 기반 IK로 보정해 기존 양손 접촉 위치를 유지한다. `AM_Pull_BoxSides`는 새 시퀀스를 참조한다.
