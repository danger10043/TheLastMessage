# Unreal 레벨 제작 및 검증 프롬프트

아래 설정과 첨부한 맵 구조도를 기준으로 대상 레벨을 Unreal 에디터에서 제작하거나 수정하고 저장해 줘. 작업 전에 기존 레벨을 열어 배치와 연결부를 확인하고, 프로젝트에서 쓰는 에셋과 블루프린트를 우선 재사용해.

## 작업 설정

- **대상 레벨** — `[레벨 에셋 경로]`
- **작업 범위** — `[기존 배치 수정 / 지정한 구역 재배치 / 처음부터 재구성]`
- **방 이름과 용도** — `[이름 / 공간의 역할]`
- **플레이어 목표** — `[통과 / 전투 / 기믹 해결 / 아이템 획득 등]`
- **참고 자료** — `[맵 구조도 / 참고 레벨 / 에셋 경로]`
- **진입·출구** — `[첫 진입 방향 / 연결할 방 / 수평·수직 연결 / 연결 높이]`
- **층수와 주요 동선** — `[층수 / 필수 경로 / 선택 경로 / 착지 지점]`
- **몬스터** — `[종류 / 수량 / 레벨 / 층과 위치 / 바닥·벽·천장 배치]`
- **기믹과 문** — `[사용할 기믹 / 작동 조건 / 스위치·문 연결 / 배치할 레벨]`
- **보상** — `[없음 / 코어 / 기타 보상과 위치]`
- **유지할 기존 요소** — `[기존 연결부 / 액터 / 설정 등]`

입력값이 비어 있으면 기존 배치와 인접 레벨을 확인해 결정하고, 결과에 가정을 적어. 도면의 범례로 연결 관계와 진행 조건을 읽고, 실제 좌표와 높이는 에디터에서 확인해. 저장 범위는 대상 레벨로 한정해. 메인 맵에서 배치할 문·퓨즈·연결 요소가 있다면 대상 레벨에는 그 요소가 들어갈 통로와 접합부를 확보해.

## 구조와 카메라

- 플레이 카메라가 **+Y에서 -Y**를 바라보고, 플레이어가 **로컬 Y=0**에서 이동한다는 기준으로 배치해. 다른 카메라나 이동면이 지정된 방은 해당 설정을 적용해.
- 카메라와 플레이어 사이를 열어 두고, 기둥과 소품은 주로 -Y 쪽에 배치해. 카메라 시점에서 계단, 발판, 문, 보상과 적이 소품에 가려지는지 확인해.
- 양쪽 끝벽은 필요한 출입구를 남겨 바닥에서 천장까지 채워. 배경 레이어를 넣을 후면은 열어 두고, 후면 기둥은 서로 겹치지 않게 정리해 바닥과 천장에 닿도록 맞춰.
- 같은 메시의 `_TwoSide` 버전이 있으면 우선 사용해. `SM_Support`, `SM_Column`, `SM_Handrail`, `SM_Box`, `SM_Container`와 `/Game/_ExternalAssets/SciFi_StarterPack/Meshes/Classic`의 소품을 방의 용도에 맞게 골라 써.
- 상자, 랙, 벤치, 스위치 등은 실제 받침면에 붙이고, 장착형 조명은 기둥이나 천장에 부착해. 이동 경로와 상호작용 지점이 플레이 카메라에서 읽히도록 밝혀.

## 바닥, 천장, 층간 이동

- 같은 층의 바닥 메시와 모듈 간격을 통일하고, 실제 충돌면이 이음새에서 이어지는지 확인해. **`SM_PackFloor` 계열은 바닥과 아래층 천장을 겸하므로 천장 메시를 덧대지 마.** 다른 바닥 메시의 밑면에 틈이 드러나면 전용 천장 패널로 마감해.
- 최상층 천장은 가까이서 올려다봐도 이음새로 바깥이 드러나지 않게 마감해. 프로젝트의 기준 규격을 따르고, 두께를 늘릴 때는 실내 천장 높이를 유지하면서 위쪽으로 확보해. 구조 마감재는 장식 천장 패널의 디테일이 보이도록 배치해.
- 계단에는 `BP_DirectionalStairs`를 사용해. 모듈 간격을 일정하게 하고, 양 끝을 실제 바닥 충돌 높이에 맞춰 점프 없이 걸어서 통과할 수 있게 해. 양 끝에 착지 공간을 확보하고, 걸리는 곳은 계단과 바닥 배치를 조정해 해결해. 별도 숨김 충돌 경사로나 임시 메시를 추가하지 마.
- 지그재그 발판이나 수직 통로에는 `/Game/Main/Blueprints/Platforms/BP_SoftPlatform_Metroidvania`를 사용해. 외형을 바꿀 때는 배치한 액터의 **`PlatformVisual`**에서 메시를 교체해. 발판 외형과 착지 범위를 맞추고, 아래에서 점프로 통과하기·위에서 착지하기·하향 점프하기를 확인해.
- 큰 몬스터가 있는 층은 스폰 위치부터 이동 경로 끝까지 실제 충돌 크기에 맞는 층고와 폭을 확보해. 상층 바닥, 보, 조명, 문틀도 머리 위 여유를 계산할 때 포함해.

## 구조 마감과 외부 면 처리

- 바닥·천장·벽을 배치한 뒤 정면뿐 아니라 **좌우 사선, 옆면, 아래에서 올려다보는 시점**에서도 확인해. 메시의 열린 단면, 내부 빈 공간, 이음새 틈이 보이면 구조용 메시나 전용 마감 패널로 막아. `_TwoSide` 재질이나 메시만으로 빈 단면이 막혔다고 판단하지 마.
- **각 층 바닥의 왼쪽 끝과 오른쪽 끝을 모두 마감해.** 2층 이상 중간 바닥, 계단 착지부, 돌출 바닥, 출구 앞 짧은 바닥에도 동일하게 적용해. 옆에서 보았을 때 내부 보나 빈 공간이 드러나지 않도록 단면 전체를 덮고, 윗면의 이동 공간과 아랫면의 천장 디테일은 유지해.
- 최상층 천장의 좌우 끝, 앞뒤 측면, 높이가 바뀌는 접합부와 벽 모서리를 마감해. 벽과 바닥·천장이 실제로 맞닿게 하고, 특히 **우측 하단과 계단 아래에 바닥이나 외벽이 빠진 구간**이 없는지 확인해. 필요한 진입·출구, 수직 개구부, 의도적으로 열린 배경 면은 유지해.
- `SM_PackFloor`처럼 바닥과 아래층 천장을 겸하는 메시에는 천장을 중복으로 덧대지 말고, 드러난 끝면과 접합부만 마감해. 짧은 착지부나 돌출부에 사용했을 때 두껍거나 내부가 드러나면, 방의 모듈 규격에 맞는 단순한 바닥·구조 메시로 교체하고 필요한 밑면과 끝면을 마감해.
- **플레이 구역 밖으로 노출된 천장 윗면과 외벽 면에는 발광, 조명 띠, 빛나는 회로 무늬, 강한 반사가 보이지 않게 해.** 조명용 재질뿐 아니라 모든 적용 재질의 발광을 확인해. 완전히 어두워야 하는 외부 면은 빛의 영향을 받지 않는 검은 재질이나 적절한 외장 마감으로 처리하고, 실내 표면과 분리해 적용해. 공용 원본 메시·재질을 수정해 다른 레벨까지 바꾸지 마. 외부 마감이 실내를 덮거나 통로·발판을 막지 않게 해.
- 문틀은 다른 완성된 레벨에서 사용하는 메시와 배치 방식을 확인해 맞춰. 문 중심과 개구부 중심을 정렬하고 바닥부터 천장까지 이어지게 해. 문틀 위·옆의 틈과 닫힌 문짝 위의 빈 공간을 마감하되, **문틀을 세로로 줄여 통행 높이를 확보하려고 하지 마.** 열린 문 아래와 문틀 내부의 실제 충돌 여유를 플레이어 및 통과할 몬스터 크기로 확인해.
- 층고가 부족하면 플레이어·몬스터를 축소하지 말고, 해당 층 바닥을 낮추거나 구조를 조정해 여유를 확보해. 바닥 높이를 바꾸면 계단, 착지부, 발판, 문, 난간, 소품, 스폰 위치와 지도 영역도 함께 맞춰. 기존 방 사이 접합 높이를 유지해야 한다면 실내에서 단차를 해결해.
- 구조 수정 후 **조명을 새 구조에 맞춰 다시 배치해.** 장착형 조명과 이미터·리시버 같은 장치는 벽·천장·기둥 또는 실제 받침면에 붙여 공중에 뜨지 않게 해. 이동 경로와 조작 지점이 보이도록 밝히고, 화면이 하얗게 날아가거나 외부 면이 빛나지 않도록 밝기와 범위를 조절해.
- 마감 완료 여부는 실제 뷰포트에서 확인한 뒤 보고해. 정면에서 가려졌다는 이유만으로 완료로 처리하지 말고, 남아 있는 틈이나 확인하지 못한 방향은 명시해.

## 방 사이 연결 통로

- 도면에서 대상 방의 **통로 수, 첫 진입로, 각 통로의 목적지와 진행 조건**을 확인해. 공용 분기가 있으면 방 경계에 필요한 통로 수를 도면과 맞춰.
- 수평 복도는 인접 레벨의 폭, 접합 높이, 방향에 맞춰. 정해진 규격이 없다면 **길이 1,200cm, 폭 800cm**를 기준으로 삼아. 복도 바닥은 접하는 층과 같은 메시를 사용하고, 양방향으로 점프 없이 걸어서 통과할 수 있도록 실제 충돌 높이를 맞춰.
- 연결용 복도는 기본적으로 천장 없이 만들고, 끝은 다음 구간을 붙일 수 있도록 열어 둬. 수직 통로는 첫 착지점과 다음 발판이 보이도록 하고, 지정된 진행 방향으로 통과할 수 있는지 확인해. 왕복 경로라면 올라오는 동선도 확인해.
- 접합부에 장식이나 소품을 두지 마. 방 내부 통과 여부와 메인 맵에서 인접 레벨까지 실제로 연결됐는지를 구분해. 레벨 인스턴스의 이동이 필요하면 대상, 방향, 필요한 이동량을 기록해.

## 문, 기믹, 보상

- 끝벽 출입문은 **문 중심의 로컬 X를 벽 개구부의 X와 맞춰**. 문 하단을 바닥 충돌면에 맞추고, 닫힌 문짝 상단과 벽 또는 문틀 사이로 빈 공간이 보이지 않게 해.
- 전동문은 `BP_ElectricDoor`를 사용해. 문틀이 필요하면 `SM_DoorFrame`을 사용하고, 문과 중심을 맞춰 바닥에서 천장 구조면까지 이어지게 해. 장식 천장의 가장 낮은 부분을 기준으로 했을 때 틈이 남으면 문틀 위를 구조 메시로 마감해. 열린 문짝은 위쪽 마감 안에 들어가고, 문틀과 문짝이 통행을 막지 않아야 해.
- 여러 스위치를 모두 켜야 열리는 문에는 `BP_AllActiveSwitchGroup`을 사용해. `GroupSwitches`에 지정된 스위치들을 등록하고 `LinkedDevices`에 대상 문을 연결해. 스위치에 문을 개별 연결하지 말고, 그룹을 통해 작동하게 해.
- 폭파 벽이 필요한 경우 기존 `BP_BombDestructibleObstacle`을 사용해. 바닥 폭과 이동면에 맞추고, 위로 우회할 수 없게 고정 벽을 천장까지 이어 붙여.
- 코어가 있으면 `/Game/Main/Blueprints/Core/BP_CorePickup`을 배치해. 디테일 창의 `Reward`에서 고정 보상은 **`Fixed`**와 지정된 보상 DA를, 세 가지 중 하나를 고르는 보상은 **`Choice`**와 프로젝트에서 쓰는 선택 설정을 사용해. 지정한 보상과 실제 획득 결과를 확인해.

## 몬스터 배치

- 레벨에 배치한 `EnemySpawnPoint`의 `Entries`에서 몬스터 BP, 수량, 레벨을 설정해. 기존 스폰 포인트가 있으면 중복을 확인하고 재사용해.
- 바닥 스폰 포인트는 **Y=0**, 실제 바닥 충돌면에서 **Z+50cm**에 둬. **Junker는 Z+150cm**에 둬. 스폰 범위 전체에 바닥과 필요한 NavMesh 볼륨 범위가 확보되어 있는지 확인해. 변경 후 네비메시 생성과 경로 연결 검증은 사용자 갱신 전에는 미검증으로 표시해.
- 벽과 천장 스폰은 **Cinder와 Sentry만** 사용해. 벽면은 실제 충돌면에서 방 안쪽으로 수직 **50cm**, 천장은 실제 충돌면에서 아래로 **50cm** 떨어뜨려. Cinder가 의도한 표면에 붙는지, Sentry가 원하는 방향을 향하는지 플레이에서 확인해.
- `SpawnRadius`는 의도한 조우 거리에 맞춰. `DespawnRadius`와 `ResetRadius`는 플레이어가 방 안에서 층을 바꾸거나 반대편으로 이동해도 거리 때문에 몬스터가 회수되거나 리셋되지 않도록 각 포인트에서 조정해. 변경은 레벨 인스턴스의 설정으로 적용해.

## NavMesh와 구역 지도

- `NavMeshBoundsVolume`의 크기는 **Brush Settings의 X·Y·Z**로 조절하고 액터 스케일은 **`(1, 1, 1)`**로 유지해. 지상 몬스터의 스폰 위치와 순찰·추격 경로를 포함해. 구조가 복잡하면 볼륨을 나눠.
- **NavMesh 빌드·갱신은 사용자가 직접 수행해. 에이전트는 Build Paths, Build Navigation, RebuildNavigation 등 네비메시를 빌드하거나 갱신하는 명령과 UI 조작을 실행하지 마.** 구조와 충돌을 정리한 뒤 결과에 **“구조가 변경되었으니 네비메시를 갱신해 주세요.”**라고 안내해. 플레이어 전용 발판은 지상 몬스터 경로에 필요한 경우에만 포함하고, 바닥 충돌, 이음새 단차, `Can Ever Affect Navigation`, 통과할 폭과 높이는 갱신 전에 확인해. 기존 네비메시 표시를 보더라도 변경 후 경로가 검증되었다고 보고하지 마.
- `/Game/Main/Blueprints/AreaMapRegion/BP_AreaMapRegion`을 배치해. **본실은 바닥 하단부터 천장 상단까지, 양쪽 벽의 바깥면과 구조물의 앞뒤 폭까지** 감싸. 직육면체가 아니면 여러 영역으로 나눠 실제 구조에 맞춰.
- 연결 복도와 수직 통로는 본실과 별도 Region으로 감싸고, 대상 방의 접합면까지 포함해. 같은 방에 속하는 모든 Region에는 **`Region Id = R_방번호`**, **`Region Name = 방 이름`**을 설정해.

## 플레이 검증과 저장

- 플레이 카메라에서 첫 진입부터 목표 지점과 각 출구까지 확인해. 수평 복도의 왕복 이동, 계단의 무점프 등반과 하향 점프 후 재등반, 발판의 통과와 착지를 해당하는 경우 각각 테스트해.
- 몬스터 스폰과 이동, 기믹 작동, 문 개폐와 통과, 보상 획득을 확인해. 떠 있는 소품·장치, 겹친 기둥, 막힌 통로, 부족한 층고, 천장 틈, 바닥 이음새, 각 층 양쪽 끝의 열린 단면, 우측 하단 누락 구조, 문틀 주변 틈과 맵 외부 면의 발광·반사를 최종 점검해.
- 대상 레벨을 저장해. 결과에는 **최종 동선, 통로별 목적지·로컬 접합 좌표·방향·폭·바닥 충돌 높이, 몬스터별 수량과 레벨, 보상 DA, NavMesh 볼륨 수, 지도 영역 수와 ID**를 적어.
- 결과에 마감한 구간과 조명 조정 내용을 적고, 네비메시는 사용자가 갱신해야 한다고 안내해. 네비메시 빌드와 변경 후 경로 검증을 수행한 것으로 기록하지 마.
- 에디터에서 값이나 충돌을 확인한 항목과 실제 플레이에서 검증한 항목을 구분해. 검증하지 못한 항목과 아직 연결되지 않은 메인 맵 접합부는 따로 표시해.
